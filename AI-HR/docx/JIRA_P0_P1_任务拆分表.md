# AI 面试官 P0-P1 Jira 任务拆分表（可直接贴 Jira）

更新时间：2026-03-25  
适用范围：AI-HR（ASR -> 题目生成 -> TTS 全链路）

## 使用说明
- 建议将“建议 Jira Key”作为 Epic/Story 前缀，再按你们 Jira 规范重命名。
- 负责人先按“角色占位”，你们可替换为真实同学。
- 工时单位为小时（h），默认 1 人全职产能约 35-40h/周。

## 关键依赖关系（建议建立 Jira 链接）
1. `AHR-P0-BE-01` 是 RTC 相关任务主前置（BE-02/BE-03/FE-01/QA-02）。
2. `AHR-P0-BE-05` 是安全与前端登录态主前置（BE-06/FE-02/QA-03）。
3. `AHR-P1-BE-06` 是治理能力主前置（BE-07/FE-01/QA-02）。
4. `AHR-P1-BE-01~05` 是质量评测主前置（FE-02/QA-01/OPS-01）。
