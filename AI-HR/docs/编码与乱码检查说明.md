# 编码与乱码检查说明

## 目标
- 统一文本文件编码为 UTF-8。
- 及时发现常见 mojibake（乱码）片段，避免进入主干分支。

## 本地检查
在项目根目录执行：

```powershell
python scripts/check_text_encoding.py --root .
```

仅检查 UTF-8 编码；检测到非 UTF-8 文件会返回非 0 退出码。

如需同时将“疑似乱码片段”作为失败条件：

```powershell
python scripts/check_text_encoding.py --root . --strict-mojibake
```

## 建议接入 CI
- PR 阶段至少执行一次 `--strict-mojibake`。
- 对于历史遗留仓库可先执行非 strict 模式，再逐步收敛到 strict。
